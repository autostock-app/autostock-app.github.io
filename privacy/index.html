Política de privacidad

Última actualización: 15-08-2024

1. Recopilación de datos

Recopilamos la siguiente información de nuestros usuarios para proporcionar y operar nuestros servicios:

Dirección de correo electrónico: Recopilamos tu dirección de correo electrónico cuando te registras en nuestra aplicación utilizando Firebase Authentication. Este correo electrónico se utiliza únicamente para la autenticación de usuarios y para asociar los datos de los productos con la tienda correspondiente.

2. Uso de los datos

La información que recopilamos se utiliza para los siguientes fines:

  • Autenticación de usuarios: verificar tu identidad y garantizar un acceso seguro.
  • Fines técnicos: vincular los datos de los productos escaneados con la tienda o entidad correspondiente.

3. Compartición de datos

No vendemos, intercambiamos ni transferimos tu información a terceros, excepto en los siguientes casos:

Proveedores de servicios: podemos compartir tu dirección de correo electrónico con proveedores que nos asisten en la operación de nuestra aplicación (por ejemplo, Firebase para autenticación y base de datos). No se comparte otra información con Firebase.

4. Seguridad de los datos

Implementamos medidas de seguridad para proteger la información que recopilamos. Los datos se almacenan de manera segura en Firebase, que cumple con prácticas de seguridad estándar de la industria.

5. Derechos del usuario

Tienes derecho a acceder, corregir o eliminar la información que tenemos sobre ti. Para ejercer estos derechos, contáctanos en autostock.public@gmail.com.

6. Cambios a esta política

Podemos actualizar esta política de privacidad periódicamente. Publicaremos cualquier cambio en esta página.

7. Contáctanos

Si tienes preguntas o inquietudes, escríbenos a autostock.public@gmail.com.
